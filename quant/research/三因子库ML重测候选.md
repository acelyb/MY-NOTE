# 101 / 191 / 158 在 ML 框架下的重测候选（2026-09-03）

> 背景：用户判断"因子数量相对主流有明显短板"，要求重过三库找出**值得加入 ML 模型**的因子。
> 关键前提：所有历史淘汰都在**线性 ICIR 框架**下得出。ML（LightGBM）的淘汰逻辑不同——
> 树模型不怕冗余、能挖非线性交互。所以"线性冗余但 ML 可能有用的"要复活重测。

## 框架：淘汰理由是否在 ML 下失效

| 线性淘汰理由 | ML 下是否复活 | 原因 |
|---|---|---|
| IC 不显著 | ❌ 不复活 | 无信号就是无信号，树也救不了 |
| 同族冗余(corr>0.6) | ✅ **复活** | 树不怕冗余，可挖条件交互（如 momentum×vol）|
| 规模/流动性伪装 | ❌ 不复活 | 伪装即伪装，ML 会放大规模暴露 |
| 正交残差不显著 | ✅ **复活** | 线性残差无信息 ≠ 非线性无信息 |
| horizon 不匹配 | 🔄 需重测 | 短 horizon 信号迁月频可能反转 |

## 二、Alpha158（Qlib）：本系统缺失的"趋势线性度"维度

158 大部分与现有 11 因子重叠，但有几类**本系统完全缺失的维度**，ML 下尤其值得加——
树模型对"趋势是否线性"这类特征敏感，线性 ICIR 用不上。

### 优先级 P0（真·新维度，本系统无）
| 因子族 | 代表 | 为什么 ML 下值得 |
|---|---|---|
| **BETA/RSQR/RESI** | 价格对时间的线性回归斜率/R²/残差 | 线性框架无此类；ML 能挖"高RSQR且高momentum"=强趋势 |
| **IMAX/IMIN/IMXD** | 距区间最高/最低价的天数位置 | 极值时序位置，ML 切"刚创新高vs久远"条件 |
| **WVMA** | 加权量价波动 | 比纯 VSTD 多价量交互 |

### 优先级 P1（kbar 上下影线——线性已结案，但 ML 重评）
上下影线日线在线性下失效，但 **158 的 kbar 是逐日值不是滚动均值**，
且 ML 能挖"上影长 + 放量"这类条件。**低优先级**，线性证据太强。
