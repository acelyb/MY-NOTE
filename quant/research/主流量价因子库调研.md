## 一、背景与定位

| 维度 | WorldQuant Alpha101 | 国泰君安191因子 | Qlib Alpha158 |
|---|---|---|---|
| 来源 | 论文《101 Formulaic Alphas》,Zura Kakushadze,2015.12(arXiv:1601.00991,Wilmott Magazine 2016) | 研报《基于短周期价量特征的多因子选股体系——数量化专题之九十三》,国泰君安金融工程(刘富兵团队),2017.06.15 | 微软 Qlib 自研(microsoft/qlib,论文 arxiv:2009.11189),DolphinDB 仅实现非设计 |
| 市场 | 美股(~2000只最流动股票),中高频 | A股(全A非ST),短周期(1~5日) | A股,短 horizon(T+1买T+2卖) |
| 因子数 | 101 | 191 | 158 |
| 数据 | 日频 OHLCV + VWAP + adv{d} + cap + 行业分类 | 日频 OHLCV + VWAP + 成交额 + 基准指数 + Fama-French三因子 | 日频 OHLCV(157/158 纯 OHLCV,仅 VWAP0 用 vwap) |
| 定位 | 公开"真实生产用"alpha公式,揭秘量化交易 | 构建"短周期交易型阿尔法"多因子选股体系 | Qlib 内置两套标准量价因子库之一(另一套 Alpha360),表格化量价特征 |

三者同属**量价短周期因子**路线:Alpha101(2015)在先,公开少量真实 alpha 公式;国泰君安191(2017)在后、系统化扩展至191 个并面向A股;Alpha158 是 Qlib 自研的"传统量价技术指标系统化整合",与 101/191 三足鼎立但来源独立。三者系统性差异在结构:**101 复杂横截面公式 / 191 技术指标混合 / 158 规整滚动统计**。

> 勘误(贯穿三库的常见误解):**Qlib 内置的是自研 Alpha158/360,并未直接内置 Alpha101 或国泰君安191**。这是最常见的误传。另:本地 `gtja191_port/factors/alpha158.py` 是 **GTJA191 的 #158 号因子**(日内振幅率 (H-L)/C),与 Qlib Alpha158 因子库**毫无关系,仅编号撞车**。

## 二、WorldQuant Alpha101

### 2.1 来源与设计理念

- **作者**:Zura Kakushadze(Quantigic Solutions LLC 总裁兼联合创始人,第比利斯自由大学商学院与物理学院教授)。
- **发表**:2015年12月9日初稿,arXiv:1601.00991,后刊于 *Wilmott Magazine* 2016(84):72-80。
- **核心主张**:论文给出 101 个**真实在产线运行**的量化交易 alpha 的显式公式——"explicit formulas – that are also computer code"。作者强调"these are not 'toy' alphas but real-life trading alphas used in production",**截至写作时其中 80 个在生产环境运行**。
- **设计哲学**:现代量化交易靠自动化"挖矿"产生海量(数十万至数百万、甚至上亿)alpha,再将它们组合成统一的"mega-alpha"交易,通过内部订单交叉节省交易成本。这 101 个因子是其中较简单者的公开样本,供研究者复现、测试、启发新想法。
- **因子性质**:多为 price-volume 因子,混合 mean-reversion(均值回复)与 momentum(动量)。论文区分 delay-0(当日信号当日交易,如 Alpha#42)与 delay-1(次日交易,如 Alpha#101)。

### 2.2 算子定义(论文原文)

> 以下为论文 Appendix A.1 的原文定义(已核验,非记忆)。表达式大小写不敏感。

| 算子 | 定义(论文原文) |
|---|---|
| `abs(x)`, `log(x)`, `sign(x)` | 标准定义;`+ - * / > < == ||` 及三元 `x ? y : z` 同理 |
| `rank(x)` | cross-sectional rank(横截面排名) |
| `delay(x, d)` | value of x d days ago(x 的 d 天前的值) |
| `correlation(x, y, d)` | time-serial correlation of x and y for the past d days(过去 d 日时序相关) |
| `covariance(x, y, d)` | time-serial covariance(过去 d 日时序协方差) |
| `scale(x, a)` | rescaled x such that sum(abs(x)) = a(默认 a=1) |
| `delta(x, d)` | today's value of x minus the value of x d days ago |
| `signedpower(x, a)` | x^a(**注意:论文原文即 `x^a`,并非 `sign(x)*|x|^a`**) |
| `decay_linear(x, d)` | 过去 d 日加权移动平均,权重为 d, d-1, …, 1(归一化到和为1,近期权重大) |
| `indneutralize(x, g)` | x 在分组 g(子行业/行业/板块等)内横截面去均值 |
| `ts_{O}(x, d)` | 算子 O 沿时序作用于过去 d 日;**非整数 d 取 floor(d)** |
| `ts_min` / `ts_max(x, d)` | 过去 d 日时序最小/最大 |
| `ts_argmax` / `ts_argmin(x, d)` | ts_max/ts_min 发生在(距今天数)第几天 |
| `ts_rank(x, d)` | 过去 d 日的时序排名 |
| `min(x,d)`/`max(x,d)` | 等价于 ts_min/ts_max |
| `sum(x, d)` / `product(x, d)` | 过去 d 日时序求和/累乘 |
| `stddev(x, d)` | 过去 d 日移动标准差 |

**关键区分**:`rank` 是**横截面**排名(跨股票,同一时刻),`ts_rank` 是**时序**排名(同一股票,跨时间)。这是两类因子构造的核心维度。

### 2.3 输入数据(论文原文)

论文 Appendix A.2 定义:

| 变量 | 含义 |
|---|---|
| `returns` | 日度 close-to-close 收益 |
| `open`, `close`, `high`, `low`, `volume` | 日度标准价量数据 |
| `vwap` | 日度成交量加权平均价 |
| `cap` | 市值(market cap) |
| `adv{d}` | 过去 d 日平均日成交额(average daily **dollar** volume) |
| `IndClass` | 行业分类占位符(GICS/BICS/NAICS/SIC 等),用于 `indneutralize(x, IndClass.level)`,level 可为 sector/industry/subindustry;同一 alpha 内多个 IndClass 不必对应同一分类体系 |

### 2.4 典型因子公式

> 以下为论文 Appendix A 原文公式(已用 PDF 原文核验)。

**Alpha#1**(条件 + 时序极值位置 + 横截面排名):
```
(rank(Ts_ArgMax(SignedPower(((returns < 0) ? stddev(returns, 20) : close), 2.), 5)) - 0.5)
```
逻辑:下跌日取收益波动率、否则取收盘价,平方后看过去5日最大值出现在哪天,横截面排名居中化。

**Alpha#6**(开盘价与成交量的时序负相关):
```
(-1 * correlation(open, volume, 10))
```

**Alpha#54**(论文原文,**勘误网上常见错误写法**):
```
((-1 * ((low - close) * (open^5))) / ((low - high) * (close^5)))
```
> 网上流传的 `... / ((low - high) + 1e-10)` 是**错的**;论文分母是 `(low-high)*(close^5)`,实现中需对分母为 0 做替换(如替换为 -0.0001)。

**Alpha#101**(论文原文,最简单的日内动量):
```
((close - open) / ((high - low) + .001))
```
> 常数是 `.001`,网上流传的 `.01` 是**错的**。论文正文称其为 "delay-1 momentum alpha":若日内上涨(close>open 且 high>low),次日做多。

### 2.5 开源实现与实现完整度

主流开源实现:`yli188/WorldQuant_alpha101_code`(862★,Python,Quantigic 实现)。从其源码核验得到以下关键事实:

- **数据字段**:实仓用 Wind 风格字段(`S_DQ_OPEN` 等);**`vwap` 并非原生字段,而是用 `成交额/成交量` 反推**——印证了 A 股 VWAP 数据需自行构造这一常见坑。
- **adv 派生**:`adv5/10/15/20/30/40/50/60/120/180` 用 `sma(volume, n)` 计算。
- **算子实现**:`ts_sum/sma/stddev/correlation/covariance/ts_rank/product/ts_min/ts_max/delta/delay/rank(pct=True)/scale/ts_argmax/ts_argmin/decay_linear` 均用 pandas rolling 实现。
- **实现完整度**:约 **83 个可跑**,因为**约 18 个因子需要行业数据(IndNeutralize + IndClass)、Alpha#56 还需 cap 市值**,该仓库未实现这些(代码中标注未实现)。

需要行业数据的因子编号(论文中含 `indneutralize` 或 `cap`):#48, #56, #58, #59, #63, #67, #69, #70, #76, #79, #80, #82, #87, #89, #90, #91, #93, #97, #100。

### 2.6 论文中的统计性质(美股)

论文对这 101 个 alpha 做了统计性质分析(样本期 **2010-01-04 至 2013-12-31**,1006 个观测,基于约 2000 只最流动美股):

- **平均持仓周期**:约 **0.6–6.4 天**(由换手率 1/T 估计)。
- **平均两两相关性**:**15.9%(中位数 14.3%)**——低相关,利于组合。
- **收益与波动**:平均日收益 `R_i` 与日收益波动率 `σ_i` **强相关**,呈现标度(scaling)性质,指数 **≈0.76**。
- **收益与换手**:对换手率 `T_i` **无统计显著依赖**。
- **换手率与相关性**:换手率(及其对数)对两两相关性 `C_ij` **解释力很弱**。
- 指标定义:年化夏普 `S_i = √252 × P&L_i/σ_i`,日换手 `T_i = D_i/V_i`(D=日均成交额,V=总投资额),cents-per-share `C_i = 100×P&L_i/shares_i`。

> 论文重点是 alpha 的**统计性质与组合特征**,并未给出每个因子的 IC/IR/夏普等A股回测指标——因为它是美股生产 alpha 的性质分析,而非A股回测报告。A股效果见[第五节](#五a股第三方复现实证alpha101)。

## 三、国泰君安191因子

### 3.1 来源与设计理念

- **研报**:《基于短周期价量特征的多因子选股体系——数量化专题之九十三》。
- **机构/团队**:国泰君安证券金融工程团队,**分析师:李辰、刘富兵、陈奥林、孟繁雪**(刘富兵团队)。
- **发布时间**:2017年6月15日。
- **核心主张**:构建"短周期交易型多因子阿尔法选股体系",区别于传统(财务/价值)多因子模型。研报认为在 A 股,交易型阿尔法收益空间比价值阿尔法更大、稳定性更强;且传统模型过度依赖市值因子,2017年风格剧变后受冲击。
- **因子构成**:研报明确"总共构建了 **191 个**基于价格和成交量数据的短周期阿尔法因子,数据维度均为日频率交易数据"。设计上借鉴墨菲《技术分析》的股价波动规律,构造动量、反转、开盘缺口、量价背离、放量等技术指标衍生因子,归类为"市场情绪类因子",对未来 **1~5 日**有预测作用。
- **风格中性**:研报强调"风格中性"控制——对行业和风格(市值等)因子敞口做约束,使策略与市场风格独立。

### 3.2 算子与变量定义(研报原文)

> 以下为研报附录2(表6)原文定义(已用 PDF 原文核验)。注意研报原文存在若干笔误,实现时需注意。

**变量**:

| 变量 | 含义 |
|---|---|
| `OPEN/HIGH/LOW/CLOSE` | 开/高/低/收 |
| `VWAP` | 均价 |
| `VOLUME` / `AMOUNT` | 成交量 / 成交额 |
| `BANCHMARKINDEXCLOSE/OPEN` | 基准指数的开/收盘价(研报原文笔误 BANCHMARK,应为 BENCHMARK) |
| `RET` | 每日收益率(收盘/前收盘-1) |
| `DTM` | `(OPEN<=DELAY(OPEN,1) ? 0 : MAX((HIGH-OPEN),(OPEN-DELAY(OPEN,1))))` |
| `DBM` | `(OPEN>=DELAY(OPEN,1) ? 0 : MAX((OPEN-LOW),(OPEN-DELAY(OPEN,1))))` |
| `TR` | `MAX(MAX(HIGH-LOW,ABS(HIGH-DELAY(CLOSE,1))),ABS(LOW-DELAY(CLOSE,1)))` |
| `HD` / `LD` | `HIGH-DELAY(HIGH,1)` / `DELAY(LOW,1)-LOW` |
| `HML SMB MKE` | Fama-French 三因子(研报笔误,常见为 HML/SMB/MKT) |
| `SELF` | 特殊变量,出现在 Alpha143,表示 t-1 日的 Alpha143 因子计算结果(**自递归**,很特殊) |

**函数/算子**:

| 算子 | 定义 |
|---|---|
| `RANK(A)` | 向量 A 升序排序(注意:研报未注明归一化到[0,1],与 Alpha101 的横截面 rank 语义需在实现时确认) |
| `MAX(A,B)` / `MIN(A,B)` | 取大/取小 |
| `STD(A,n)` / `MEAN(A,n)` / `SUM(A,n)` / `PROD(A,n)` | 过去 n 日标准差/均值/和/累乘 |
| `CORR(A,B,n)` / `COVIANCE(A,B,n)` | 过去 n 日相关系数/协方差(研报笔误 COVIANCE,应为 COVARIANCE) |
| `DELTA(A,n)` | `A_i - A_{i-n}` |
| `DELAY(A,n)` | `A_{i-n}` |
| `TSMIN/TSMAX(A,n)` | 过去 n 日最小/最大值 |
| `TSRANK(A,n)` | 序列 A 的末位值在过去 n 天的顺序排位 |
| `SIGN(A)` | 符号函数(A>0→1,=0→0,<0→-1) |
| `LOG(A)` / `ABS(A)` | 自然对数 / 绝对值 |
| `COUNT(condition,n)` | 前 n 期满足 condition 的样本个数 |
| `REGBETA(A,B,n)` | 前 n 期 A 对 B 回归的回归系数(**Alpha101 没有**) |
| `REGRESI(A,B,n)` | 前 n 期 A 对 B 回归的残差(**Alpha101 没有**) |
| `SMA(A,n,m)` | `Y_{i+1} = (A_i*m + Y_i*(n-m)) / n`,递归指数加权(**Alpha101 没有**) |
| `WMA(A,n)` | 前 n 期加权平均,权重为 `0.9^i`(i 为距当前间隔) |
| `DECAYLINEAR(A,d)` | 移动加权平均,权重 d,d-1,…,1(和为1,对应 Alpha101 的 decay_linear) |
| `SUMIF(A,n,condition)` | 前 n 项条件求和 |
| `FILTER(A,condition)` | 筛选符合 condition 的样本 |
| `HIGHDAY(A,n)` / `LOWDAY(A,n)` | 前 n 期最大/最小值距当前的间隔(对应 Alpha101 的 ts_argmax/ts_argmin) |
| `SEQUENCE(n)` | 生成 1~n 等差序列 |
| `SUMAC(A,n)` | 前 n 项累加 |
| `&` / `||` / `A?B:C` | 逻辑与 / 逻辑或 / 三元条件 |

**与 Alpha101 算子的关键差异**:191 多了**回归类算子**(`REGBETA`/`REGRESI`)、**递归指数加权**(`SMA(A,n,m)`)、`WMA`、`COUNT`、`SUMIF`、`FILTER`、`SEQUENCE`、`SUMAC`;并引入了**基准指数**和 **Fama-French 三因子**作为变量(用于风格中性),以及一个**自递归变量 `SELF`**(Alpha143)。

### 3.3 典型因子公式

> 以下为研报表6原文(已用 PDF 原文核验)。注意 PDF 排版导致部分公式有 OCR 瑕疵(如 `&` 逻辑符、个别 `L` 应为 `LOW`),实现时需对照研报校正。

**Alpha1**(对应 Alpha101 的 alpha#2):
```
(-1 * CORR(RANK(DELTA(LOG(VOLUME), 1)), RANK(((CLOSE - OPEN) / OPEN)), 6))
```

**Alpha2**:
```
(-1 * DELTA((((CLOSE - LOW) - (HIGH - CLOSE)) / (HIGH - LOW)), 1))
```

**Alpha9**(用到递归 SMA):
```
SMA(((HIGH+LOW)/2-(DELAY(HIGH,1)+DELAY(LOW,1))/2)*(HIGH-LOW)/VOLUME, 7, 2)
```

**Alpha21**(用到 REGBETA 和 SEQUENCE):
```
REGBETA(MEAN(CLOSE,6), SEQUENCE(6))
```

**Alpha25**(对应 Alpha101 的 alpha#39):
```
((-1 * RANK((DELTA(CLOSE, 7) * (1 - RANK(DECAYLINEAR((VOLUME / MEAN(VOLUME,20)), 9)))))) * (1 + RANK(SUM(RET, 250))))
```

**Alpha30**(用到 Fama-French 三因子与 REGRESI):
```
WMA((REGRESI(CLOSE/DELAY(CLOSE)-1, MKT, SMB, HML, 60))^2, 20)
```

**Alpha54**(对应 Alpha101 的 alpha#18):
```
(-1 * RANK((STD(ABS(CLOSE - OPEN)) + (CLOSE - OPEN)) + CORR(CLOSE, OPEN, 10)))
```

### 3.4 与 Alpha101 的关系

- **时间**:Alpha101(2015底)在先,191(2017)在后。
- **重合**:191 的 Alpha1 即 Alpha101 的 alpha#2;191 的 Alpha25 即 Alpha101 的 alpha#39;191 的 Alpha54 即 Alpha101 的 alpha#18——说明 191 直接借鉴/收录了部分 Alpha101 因子。
- **扩展**:191 在 Alpha101 量价算子基础上,增加了回归算子、递归加权、基准指数与 Fama-French 三因子(用于风格中性),并系统化到 191 个,面向 A 股短周期。
- **定位差异**:Alpha101 是"公开少量真实 alpha 公式"以揭秘量化;191 是"构建完整短周期交易型多因子选股体系"并提供详尽回测。

### 3.5 研报中的回测效果(A股)

研报给出了非常详尽的一手回测数据。

**单因子检验(全A非ST,行业+风格正交后回归)**:

不同预测周期下所有因子的年化因子收益率均值与 IR 均值:

| 预测周期 | DAY1 | DAY2 | DAY3 | DAY4 | DAY5 |
|---|---|---|---|---|---|
| 年化因子收益率均值 | 6.85% | **8.08%** | 6.09% | 5.42% | 4.78% |
| 因子收益率 IR 均值 | **2.57** | 2.11 | 1.73 | 1.26 | 1.05 |

- 大部分因子年化收益率在 **2%–10%**,极少超 15%。
- 对未来 **2 天**预测平均收益最高,T+3 后递减;**预测周期极限为 T+4 日**(T+4 后 IR 不显著)。
- **因子相关性**:因子收益率相关系数分布均值仅 **-0.0057**,**94% 的因子收益率相关系数绝对值 < 0.1**——低相关,利于组合。

**模型预测能力(2010.01-2017.04,全A非ST,T+1)**:
- 日度 IC 均值 **0.057**,T-Stat **18.23**,日度 IC 胜率 **88.7%**(接近90%);仅 2015 股灾期间有波动,其余稳定。

**因子个数 vs 预测能力**:按单因子 IR 排序逐步增加因子数,IC 单调上升(20个:0.0338 → 191个:0.057),边际递减但绝对能力持续提升——"因子数量还远未达到边界"。

**风格中性多因子策略(2012.01-2017.04,基准中证500,全A非ST,单边交易成本0.1%+印花税0.1%即 Tc=0.3%,行业敞口±5%,风格敞口±0.1,次日开盘价成交)**:

| 指标 | 数值 |
|---|---|

## 六、Qlib Alpha158 因子库

> 本节调研于 2026-09-03,来自 [[qlib-alpha158-survey]]。用户原话提到"vwapAlpha158"并给 DolphinDB 教程链接。经核实:Alpha158 因子库**源自微软 Qlib 自研**(DolphinDB 只是实现了它),不是 GTJA191 的 #158 号因子。本节厘清来源、因子构成、所需数据、Qlib 官方基准回测表现,并评估对本系统的移植价值与路线。

### 6.1 来源与定位(一手核实)

| 维度 | 结论 |
|---|---|
| 原始出处 | **微软 Qlib**(microsoft/qlib,48k★),论文 arxiv:2009.11189 |
| 性质 | Qlib 内置两套标准量价因子库之一(另一套 Alpha360) |
| 常见误解 | ❌ 不是 WorldQuant Alpha101 的一部分;❌ 不是 GTJA191 的 #158;❌ 不是 DolphinDB 自研 |
| DolphinDB 角色 | 仅用 DolphinDB 脚本实现了全部 158 个因子函数(`alpha158.dos` 模块),非设计者 |

> 勘误:本地 `gtja191_port/factors/alpha158.py` 是 **GTJA191 的 #158 号因子**(日内振幅率 (H-L)/C,已测 IC=-0.0842),与 Qlib Alpha158 因子库**毫无关系**,仅编号撞车。本节省略此重复说明(已并入文首勘误)。

### 6.2 因子总数与构成(源码级,来自 qlib/contrib/data/loader.py)

**总计 158 个** = 9(kbar)+ 4(price 默认)+ 145(rolling 全量)。

#### 1. kbar 类(9个)—— K线形态
KMID/KLEN/KMID2/KUP/KUP2/KLOW/KLOW2/KSFT/KSFT2,全部刻画当日 K 线各部分相对开盘价或振幅的比例。**本质就是上下影线/实体形态**——本系统已结案的"上下影线日线"路线在此有完整对照。

#### 2. price 类(默认4个)
OPEN0/HIGH0/LOW0/VWAP0 = 当日开/高/低/VWAP 除以收盘价。**唯一用到 VWAP 的就是 VWAP0 这一个因子**。

#### 3. rolling 类(145个 = 29算子 × 5窗口[5/10/20/30/60日])
| 算子族 | 算子 | 数量 |
|---|---|---|
| 价格趋势 | ROC/MA/STD/BETA/RSQR/RESI/MAX/MIN/QTLU/QTLD/RANK/RSV | 60 |
| 极值位置 | IMAX/IMIN/IMXD | 15 |
| 价量相关 | CORR/CORD | 10 |
| 涨跌统计 | CNTP/CNTN/CNTD/SUMP/SUMN/SUMD(类 RSI) | 30 |
| 纯量 | VMA/VSTD/WVMA/VSUMP/VSUMN/VSUMD | 30 |

**结构特点**:固定 5 个窗口的滚动统计,规整统一。与 WQ101(复杂横截面公式)、GTJA191(技术指标混合)风格不同——Alpha158 偏"传统量价技术指标的系统化整合"。

### 6.3 所需输入数据

| 字段 | 用到该字段的因子 |
|---|---|
| open, close, high, low | kbar 全部 + rolling 多数 |

### 6.5 与本系统的关系评估

#### 6.5.1 重叠度(核心问题)
Alpha158 的 158 个里,大量因子本系统**已有等价物**:
- MA/STD/MAX/MIN/RANK/ROC → 本系统 momentum/reversal/low_vol 已覆盖趋势与波动
- RSV/CNTP/SUMP(类 RSI)→ 与 reversal(60) 重叠
- CORR/CORD(价量相关)→ 与 GTJA191 alpha99(量价协方差,已测弃用)同维度
- kbar 上下影线 → 本系统已结案(上下影线日线失效)
- VMA/VSTD(量波动)→ 与流动性代理重叠(已验证流动性是伪装高发区)

**独立新维度候选**(本系统缺失的):
- **BETA/RSQR/RESI**:价格对时间的线性回归斜率/R²/残差——本系统无"趋势线性度"因子
- **IMAX/IMIN/IMXD**:距区间最高/最低价的天数位置——本系统无"极值时序位置"因子
- **WVMA**:加权量价波动——比纯 VSTD 多一层价量交互

#### 6.5.2 移植 ROI 判断
| 维度 | 评估 |
|---|---|
| 数据成本 | 低(157/158 纯 OHLCV,1 个补 VWAP) |
| 实现成本 | 中(29 个 rolling 算子要逐个写,但结构规整可批量) |
| 增量预期 | **中低**——大量因子与现有重叠,真增量可能就 BETA/RSQR/RESI/IMAX/IMIN/WVMA 这几个 |
| 风险 | Alpha158 是为**短 horizon + ML 表格模型**设计的;本系统是**月频 + 线性 ICIR**,因子有效性可能随 horizon 漂移 |

### 6.6 建议路线(供决策,未改系统源码)

**路线A(推荐):只移植"独立新维度"子集,走标准 5 道门**
不移植全 158 个,只挑本系统缺失的 6~8 个(BETA/RSQR/RESI/IMAX/IMIN/IMXD/WVMA),逐个走 [[new-factor-process-checklist]]:
- 门1 IC 检验(月频 horizon=21,注意 Qlib 基准是短 horizon,方向可能反转)
- 门2 vs 当前 11 因子相关性(用 verify_candidates_gate23.py,对照基准=当前 11 因子非旧快照)
- 门3 正交残差
- 门4 walk-forward A/B(baseline=当前 20 只因子集)

**省时点**:门1-3 不跑组合,几秒一个。筛完真增量的再进组合 A/B。

**路线B:全量移植 + ML 表格化(重)**
照搬 158 个 + 上 LightGBM/DoubleEnsemble 合成。但:
- 本系统 ML 分支已实测跑输线性([[ml-ab-negative-excess-diagnosis]]),且因子数 11→158 易过拟合
- Alpha158 设计 horizon 与本系统不同,需先验短 horizon 有效性再迁月频
- ROI 不明,不推荐作首选

**路线C:暂不移植,优先验证现有 CPPI/仓位层**
当前 CPPI 真 A/B 在跑(仓位层回撤攻坚),因子层已 11 个够用。**因子扩展的边际收益(路线A)可能低于仓位层 CPPI 的边际收益**(CPPI 仿真把回撤 -68%→-31%)。建议等 CPPI 真 A/B 出结果再定因子层是否需要扩。

### 6.7 与既有调研的关系

- 本系统已完整调研并实测:WorldQuant Alpha101(文献级,未全量实测)、GTJA191(190/191 全量实测,见 [[alpha101-gtja191-survey]])
- **Alpha158 是第三个主流量价因子库**,定位"Qlib 自研的表格化量价特征",与 101/191 三足鼎立但来源独立
- 三者共性:A 股上单因子 IC 都在 0.03~0.05 区间,无明显"银弹";差异在结构(101 横截面公式 / 191 技术指标混合 / 158 规整滚动统计)

## 七、业界使用情况与常见问题

### 使用情况

- **Alpha101**:论文明确 80 个在生产环境运行(美股,2015);开源社区有大量实现(yli188/WorldQuant_alpha101_code 862★ 等);学术界常作为因子工程基准。但需注意:**微软 Qlib(48k★)内置的是自研的 Alpha158/Alpha360 因子集(受 Alpha101 启发),并未直接内置 Alpha101 或国泰君安191**——这是常见误解,文档特此勘误。
- **191**:国泰君安研报提出后,成为 A 股量价因子的经典基准;社区有 SelenaMa9812/Guotai-Junan-191-Alpha(63★,含研报PDF)等实现;QUANTAXIS(11.1k★)有 QAFactor 因子研究框架但未直接内置191因子库。实际生产中多作为因子池的一部分,经筛选与合成后使用。
- **Alpha158**:Qlib 内置、社区广泛用作 ML 基准特征集(尤其表格模型 LightGBM/XGBoost/DoubleEnsemble);DAT (DoubleEnsemble) 常被用作 CSI300/CSI500 alpha 研究的评测基线。

### 常见问题与坑

1. **VWAP 数据缺失**:Alpha101 大量因子(如 #5/#11/#41/#42)依赖 VWAP,而 A 股 VWAP 不是原生日线字段,需用 `成交额/成交量` 反推。191 因子同样依赖 VWAP 与成交额(AMOUNT)。158 仅 VWAP0 一个依赖 VWAP(其余 157 纯 OHLCV)。数据质量直接影响因子效果。
2. **行业数据**:Alpha101 约 18 个因子需 `indneutralize` + 行业分类,Alpha#56 需 cap 市值;很多开源实现直接跳过这些因子,导致"实现不全"(如 yli188 仅可跑约 83 个)。191 部分因子需基准指数与 Fama-French 三因子。
3. **过拟合与样本期依赖**:国泰君安 50.2% 年化超额来自 2012-2017 小盘强势期(2015 单年贡献巨大),2017 年后小盘风格转弱,这类策略普遍回撤。直接照搬历史参数有过拟合风险,需走样本外验证与滚动训练(WalkForward)。
4. **换手与成本**:短周期因子换手极高(191 策略年化双边 48.2 倍),交易成本敏感——研报显示 Tc 从 0.3% 升到 1% 时超额从 50.2% 降到 20.7%。158 同样为短 horizon 设计,换手成本需估算。实盘必须做换手罚函数优化与冲击成本估算。
5. **单因子失效**:无论 Alpha101 还是 191,单因子在 A 股大量失效(第三方实证 15 选 3),需筛选 + 中性化 + 正交化 + 合成才有效。因子有效期短(191 研报:预测极限 T+4 日)。158 单因子 IC 0.03~0.05 亦需 ML 合成才体现价值。
6. **公式勘误**:网上流传的 Alpha101 公式有常数错误(如 alpha#54 分母、alpha#101 的 `.001` 常数),实现时务必对照论文原文 PDF;191 研报 PDF 有排版 OCR 瑕疵与笔误(如 COVIANCE/COVARIANCE、BANCHMARK/BENCHMARK、HML SMB MKE),需校正。

### 在现代量化系统中的应用建议

- 作为**因子池**而非单因子使用;先做单因子检验(IC/ICIR/分层收益/换手),筛掉失效因子。
- 统一预处理:**去极值(MAD/3σ)→ 标准化(z-score)→ 行业中性化 + 市值中性化**。
- 处理因子相关性:对称正交化(Löwdin)或施密特正交化。
- 合成:滚动 OLS 线性合成,或用 LightGBM/树模型/神经网络做非线性合成(注意防未来函数、WalkForward 切分)。
- 风险控制:行业与风格敞口约束,换手罚函数,容量估算(个股成交额占比上限)。158 尤其配合表格模型(ML 合成)使用,单因子价值有限。
- 持续监控因子衰减,定期再筛选与再训练。

> 注:第三小节"常见问题 4/5"在 191 原文基础上,补充了 158 对应口径(短 horizon / ML 合成提效),以覆盖三库。
